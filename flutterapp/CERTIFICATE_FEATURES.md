# Certificate Management Features

## 🎯 Новые возможности системы сертификатов

### 📥 **Скачивание PDF сертификатов**
- **Местоположение**: `/Users/user1/Desktop/cert_verifier_project/generate_cert/certificates_batch/`
- **Функция**: Массовое скачивание всех сгенерированных PDF файлов
- **Как использовать**:
  1. Сгенерируйте сертификаты через интерфейс
  2. Нажмите кнопку "Share All PDFs" 
  3. Выберите способ распространения (AirDrop, Email, и др.)

### 📧 **Email рассылка сертификатов**
- **SMTP поддержка**: Gmail, Outlook, и другие SMTP серверы
- **Автоматическое прикрепление**: PDF сертификаты автоматически прикрепляются к письмам
- **Персонализация**: Каждое письмо содержит имя участника

#### Настройка Email:
```
SMTP Server: smtp.gmail.com
Port: 587
Email: your.email@gmail.com  
Password: App Password (не обычный пароль!)
```

#### Для Gmail:
1. Включите 2FA в вашем Google аккаунте
2. Создайте App Password: https://myaccount.google.com/apppasswords
3. Используйте этот App Password в приложении

### 🔧 **Техническая реализация**

#### Структура файлов:
```
cert_verifier_project/
├── generate_cert/
│   ├── generate.py          # Python скрипт генерации
│   └── certificates_batch/  # 📁 Папка с PDF сертификатами
│       ├── Participant_Name_cert.pdf
│       └── Participant_Name_qr.png
├── participants.csv         # Исходные данные
└── public/
    └── participants.json    # Данные для верификации
```

#### Поддерживаемые форматы:
- **PDF**: Готовые к печати сертификаты
- **PNG**: QR коды для верификации  
- **JSON**: Данные для веб-верификации

### 📱 **Интерфейс управления**

#### 1. Certificate Generator Screen
- ⚙️ **Конфигурация URL** - настройка ссылки верификации
- 📤 **Загрузка CSV** - импорт участников
- 🏭 **Генерация сертификатов** - запуск Python скрипта
- 📊 **Предпросмотр участников** - проверка данных

#### 2. PDF Management Section  
- 📱 **Share All PDFs** - массовое распространение
- 📧 **Send Emails** - рассылка по почте
- 📋 **Список файлов** - просмотр доступных сертификатов
- ⏳ **Прогресс отправки** - отслеживание email рассылки

### 🚀 **Сценарии использования**

#### Администратор мероприятия:
1. Загружает CSV с участниками
2. Генерирует сертификаты
3. Выбирает: скачать все PDF или отправить по email
4. Настраивает SMTP для автоматической рассылки

#### Массовая рассылка:
1. Настраивает email конфигурацию
2. Запускает "Send Emails"
3. Каждый участник получает персональное письмо с прикрепленным PDF
4. В письме содержится ссылка для верификации сертификата
